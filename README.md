# Onyx Scents website template

A responsive static storefront for GitHub Pages.

## Publish it
1. Create a new GitHub repository, such as `onyx-scents`.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to show the published URL.

## Customize it
In `index.html`, search for `const products` to change product names, categories, prices, descriptions, and image URLs. Replace the sample email address and use photos you have permission to use.

## Important
This is a front-end template. The product filters and shopping cart work in the browser, but checkout does not process payments or create real orders. The newsletter form is also a demo. Connect a real ecommerce checkout (such as Shopify or Stripe), and configure shipping, taxes, privacy, returns, and customer support before accepting orders.
